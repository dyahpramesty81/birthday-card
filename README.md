# Birthday Card ✨

Website kartu ucapan ulang tahun interaktif, responsif, dan siap dipublikasikan lewat GitHub Pages.

## Cara mengganti nama teman
1. Buka `index.html`.
2. Cari bagian `const FRIEND_NAME = "Beautiful Soul.";`
3. Ganti `Beautiful Soul.` dengan nama temanmu, misalnya `Nadia`.
4. Simpan file.

## Cara upload ke GitHub
1. Buat repository baru di GitHub, misalnya `birthday-card`.
2. Pilih **Public** jika ingin websitenya bisa dibuka lewat tautan publik.
3. Upload `index.html` dan `README.md` ke repository (bisa lewat **Add file → Upload files**).
4. Buka **Settings → Pages**.
5. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
7. Tunggu beberapa saat. GitHub akan menampilkan alamat website di halaman Pages.

## Catatan
- Website ini hanya memakai HTML, CSS, dan JavaScript—tidak perlu instalasi atau build.
- Koneksi internet diperlukan untuk memuat font Google Fonts; tanpa itu website tetap bisa dibuka dengan font cadangan.
- Semua ucapan bisa diedit langsung di `index.html`.
